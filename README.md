# БаоКод

Нативный Android MVP на Kotlin и Jetpack Compose. Игрок не печатает код: он собирает программу из карточек, среди которых есть отвлекающие строки. После успешного запуска открывается свободная смена — мини-симулятор кафе.

## Что уже есть

- два обучающих уровня с разными правильными последовательностями и ложными командами;
- выбор и удаление карточек одним касанием;
- локальное открытие следующего уровня через DataStore — прогресс переживает перезапуск;
- режим кафе: готовить бао, подавать заказ, звать посетителя; во втором уровне доступен помощник;
- спокойная японская палитра без внешних ассетов, поэтому приложение запускается сразу после синхронизации.

## Запуск

1. Откройте корневую папку проекта в Android Studio (Ladybug или новее).
2. Дождитесь Gradle Sync и выберите эмулятор/телефон с Android 8.0+.
3. Нажмите Run.

Для production-версии следующий разумный этап — вынести каталог уроков в JSON/API и добавить сервер только для аккаунта, облачной синхронизации и рейтинга. Сам геймплей должен оставаться офлайн-доступным.

## Структура

Сейчас это намеренно компактный MVP: правила уроков и состояния изолированы от Compose-компонентов через небольшие модели `Lesson` и `CodeBlock`; хранение прогресса — единственная инфраструктурная зависимость. При добавлении десятков уроков стоит вынести их в `LessonRepository`, а экран — в `ViewModel`, не размножая абстракции до появления реальной потребности.
